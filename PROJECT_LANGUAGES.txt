PART 2: DETAILED SYSTEM MAPPING & LAYER ARCHITECTURE
================================================================================

1. CLIENT & KIOSK PORTAL (Frontend):
   - Languages: TypeScript (TSX), JavaScript (ES2024), HTML5, CSS3
   - UI Architecture: React 18 component tree with Tailwind CSS utility classes
   - Visual Experiences: Three.js 3D human anatomy model for spatial symptom localization,
     accompanied by Framer Motion entrance/exit transitions and spring physics
   - Voice Engine: Browser Web Speech API supporting real-time recognition & speech synthesis

2. BACKEND & SERVICE LAYER (Node.js & Python):
   - Node.js API Service: TypeScript + Express.js / NestJS architecture providing authentication,
     RBAC middleware, patient triage routing, and prescription generation
   - AI Microservice: Python FastAPI service powering OCR extraction (pytesseract)
     and LLM triage summarization, communicating via JSON REST payloads
   - Testing Suite: Playwright E2E test automation verifying multi-step clinical check-in flows

3. DATA, PLATFORM & HEALTHCARE INTEROPERABILITY:
   - Primary Relational Database: PostgreSQL managed via Supabase (Auth, RLS, Realtime, Storage)
   - Resilient Fallback: In-memory dual-mode seed system for zero-config offline evaluations
   - Healthcare Interoperability: HL7 FHIR Release 4 Document Bundles (JSON format)
   - National Health Stack: ABDM M1 (ABHA Creation), M2 (Discovery & Linking), M3 (HIP/HIU Flow)
